# LOCKNLOAD Brand Guidelines

Interactive web edition of the LOCKNLOAD brand guidelines (GDVX780, Fall 2026, Spencer Wilcox).

## Fonts
Display and body type load from an Adobe Fonts web project. Paste the project's embed link into
`index.html` where the `ADOBE FONTS` comment sits in the `<head>`. Without it, the page falls back
to Archivo Expanded and Saira Semi Condensed from Google Fonts.

## Publish on GitHub Pages
Settings → Pages → Deploy from a branch → `main` / root.
