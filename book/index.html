Book export

Open a version, wait for it to finish loading, then save it as a PDF from Chrome. The pages use the real BC Barell from your Adobe Fonts web project.

Proof + guides
Spec pages, then every page on 11 × 17 with bleed, margins, columns, rows and ring holes shown.
Print
Every page on 11 × 17 with crop marks and punch ticks. No guides. Use this to print.
Spreads
Each spread as it reads in the book: visual above the rings, copy below.

Save as PDF in Chrome

  1. Open a version and wait about 10 seconds so all fonts and images load.
  2. Press Ctrl+P (Cmd+P on a Mac).
  3. Set Destination to Save as PDF.
  4. Under More settings: Paper size should already read 17 × 11 (or 12 × 13.5 for Spreads). Set Margins to None, Scale to Default, and tick Background graphics.
  5. Click Save.

Use Chrome or Edge. Safari and Firefox ignore the custom page size. Body text uses a stand-in until Address Sans Pro is added to the Adobe web project; then it switches automatically.
